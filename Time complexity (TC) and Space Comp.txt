Time complexity (TC) and Space Complexity (SC):
1. What is time complexity?
=> Rate of increase in time with respect to input size. 

TC -> Big-oh Notation -> O(your_time_taken (15))
TC -> O(8N^6+ 3N^2+15)
TC -> O(8N^30)

N = 10^5

Example: 
for i in range (1,6):
	print ("Anirudh")

2. Why interviewer asks TC & SC?
=> 
1. Alaways calculate TC in terms of worst case
2. Avoid the constant values
3. Avoid lower values/bound

3. Different types of TC & SC?
=> Different types of Time complexity
1. Big-oh(0) -> Worst Case [Upper bound]
2. Theta(Θ) -> Average Case ((Worst case + best case)/2)
3. Omega(Ω) - > Bast Case [Lower bound]

4. Rules to calculate TC & SC. 
=> Example: 
1. O(N^2)
2. O(N(N+1)/2)

Space Complexity:
Memory space -> Big-oh Notation

1. Auxiliary Space -> The extra space used to solve the problem. 
+
2. Input Space -> The space used to store the input. 

Example: [array / list [N]] -> SC -> O(N)

2. Time Limit Exceeded Error [TLE]:
=> (N log N) -> Time complexity will be reduced for O(N^2)
